


## I1: Conoscenze e Competenze tecniche operative 

- Possiede conoscenze afferenti ai contenuti disciplinari richiesti  
- Sa applicare quanto appreso 
- Dimostra di conoscere i concetti teorici afferenti ai contenuti disciplinari richiesti. 
- Applica consapevolmente le conoscenze per risolvere correttamente le problematiche progettuali proposte 
- Se richiesto, applica consapevolmente le conoscenze per scegliere/confrontare dispositivi e strumenti (elettronici-informatici) in base alle caratteristiche funzionali  

| Livelli di Valutazione  | LIV  | PESO  |
|:---|:---:|:---:|
| Conoscenza completa dei contenuti, con eccellente grado di dettaglio  Svolgimento completo, senza imprecisioni  | 5  |                         |
| Conoscenza completa dei contenuti, con ottimo grado di dettaglio  Svolgimento completo, con un numero molto ristretto di imprecisioni  | 4,5  |  |
| Conoscenza completa dei contenuti, con grado buono di dettaglio  Svolgimento completo, con un ristretto numero di imprecisioni e/o errori marginali  | 4  |  |
| Conoscenza non del tutto completa dei contenuti, con discreto grado di dettaglio  Svolgimento completo, con alcune imprecisioni e/o errori marginali  | 3,5  |  |
| Conoscenza non del tutto completa dei contenuti, con accettabile grado di dettaglio  Svolgimento limitato ai punti essenziali, con alcune imprecisioni e/o errori marginali  | 3  |  |
| Conoscenza limitata ed imprecisa dei contenuti  Svolgimento non completo, con un numero molto ristretto di errori significativi  | 2,5  |  |
| Conoscenza molto limitata ed imprecisa dei contenuti  Svolgimento non completo, con alcune carenze rilevanti e/o errori significativi  | 2  |  |
| Molteplici e gravi lacune nella conoscenza dei contenuti  Svolgimento non completo, con molteplici carenze rilevanti e/o errori significativi  | 1,5  |  |
| Conoscenze assenti circa i contenuti  Consegna in bianco oppure svolgimento appena accennato, con molteplici carenze rilevanti e/o errori significativi  | 1  |  |
